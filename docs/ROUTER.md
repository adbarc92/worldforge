# WorldForge router

WorldForge (formerly Canon Builder) is a RAG worldbuilding tool that detects contradictions in your canon. v1.0.0 is code-complete; launch is gated on the demo video and community ramp.

Map: [index.md](index.md) one line per doc. Memory: [state.md](state.md).

- [ARCHITECTURE.md](ARCHITECTURE.md): how it is built

- [ROADMAP.md](ROADMAP.md): phases 2 to 8
- [LAUNCH_TODOS.md](LAUNCH_TODOS.md): what is outstanding
